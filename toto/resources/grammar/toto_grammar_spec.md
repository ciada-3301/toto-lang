# Toto Grammar Specification

Authoritative grammar reference synthesised from:
1. Toby Anderson, *Toto–English Dictionary*, Totopara Community, 2017.
2. Guha et al., *Morphological Analysis of Toto*, Adamas University, 2025.

## Word Order
- SOV (Subject – Object – Verb)
- Postpositional (case suffixes, not prepositions)
- Adjectives precede or follow head noun

## Pronominal System
| Person | Nominative | Possessive | Objective |
|--------|-----------|-----------|----------|
| 1SG    | ka        | kung / kako | kahing   |
| 2SG    | nati      | nako      | natihing  |
| 3SG    | ako / aku | akoko     | akohing   |
| 1PL    | kiko / kibi | kibiko  | kikohing  |
| 3PL    | akuko / abih | akukoko | akukohing |

## Case Suffixes
- Nominative: unmarked
- Accusative: -he / -hing
- Dative: -hing / -ta
- Locative: -ta / -sho
- Instrumental: -sho / -sha
- Ablative: -sho
- Genitive: -ko
- Definite: -ha
- Plural: -bi

## Tense/Aspect
- Present: -na / -mi
- Past: -mi / -na
- Future: -ro
- Progressive: -dang-na / -ding-na
- Perfect: -pate-na / -pate-mi / -pu-ro

## Mood
- Imperative: bare stem or -ko
- Negative ('should not'): -dinga
- Prohibition ('must not'): -majo
- Copula: mi / ha
